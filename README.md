# Практические работы 1–5, вариант 32

Файлы:
1. `pr1_variant32_dynamic_szzi.py` — динамическое программирование, выбор комплекса СрЗИ.
2. `pr2_variant32_financing.py` — оптимальное финансирование мероприятий ИБ.
3. `pr3_variant32_replacement.py` — замена средства защиты информации.
4. `pr4_variant32_main_criterion.py` — многокритериальное управление, метод главного критерия.
5. `pr5_variant32_multicriteria.py` — многокритериальное управление, свёртки и метод идеальной точки.

Запуск каждого файла:
```bash
python имя_файла.py
```

Зависимости:
```bash
pip install matplotlib numpy
```

Каждая программа печатает исходные данные варианта 32, ход расчёта, итоговое решение и сохраняет графики в отдельную папку `pr*_output`.
